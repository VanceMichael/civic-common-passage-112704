# 资料协议

segments 描述双向通行的段，access 列出可以作为住户通路的属性，crews 是此段可同时进入的搬运组数。占满容量的搬运段不作为住户保底通路。sectors 的 access 给出保底路径每一段都应支持的属性，exits 标出室外的节点。moves 的区间为 UTC 左闭右开。巡查表 paper 在同一来源稳定，rev 每次更正递增，observedAt 是现场观察时刻。承包方与巡查人员通过各自有权限的作业身份回报。

siteTickets 是承包方在现场签的作业联络单，enteredAt 指实际进场。hazardShifts 是现场核实方发出的逐段交还记录，incident 是该轮在现场使用的清障编号。
